# 🌤️ Weather App Android

Application Android permettant de consulter la météo d'une ville.

## Fonctionnalités

- Recherche par ville
- Température actuelle
- Humidité
- Vitesse du vent
- Prévisions météo

## Technologies

- Kotlin
- Android Studio
- Retrofit
- OpenWeather API
- MVVM

## Compétences démontrées

- Consommation d'API REST
- Parsing JSON
- Architecture MVVM
- Android UI
